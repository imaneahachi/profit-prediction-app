# 💰 Système de Prédiction de Profits d'Entreprise

Application web interactive développée avec **Streamlit** pour prédire les profits d'une entreprise à partir de données historiques, en utilisant la **régression linéaire multiple**.

---

## 🎯 Fonctionnalités

- 📊 Chargement et exploration du dataset 50_Startups
- 🧹 Prétraitement automatique (imputation, encodage, normalisation)
- 📉 Réduction de dimensionnalité (PCA)
- 🤖 Modèle de régression linéaire multiple
- 📈 Visualisations interactives avec Plotly
- 🎨 Interface utilisateur intuitive

---

## 🛠️ Technologies utilisées

- **Python 3.14**
- **Streamlit** — Interface web
- **Pandas / NumPy** — Manipulation des données
- **Scikit-learn** — Machine Learning
- **Plotly** — Visualisations interactives
- **Category Encoders** — Encodage des variables catégorielles
